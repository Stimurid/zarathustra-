# G-S23 MODE AND REFLEXIVITY GOVERNOR — PROMPT PACK v0.1 candidate

Critical invariants live in schemas/policies; this pack is an execution projection, not the sole authority.

## P0 — Assembly selector
Given Scene/Telos, authority, applicability, origin/status, ownership, attention/memory/imagination signals, return either `DIRECT_BYPASS` or a `CouncilRecipe`. Select the **minimum sufficient** organ set. Default persona selection is `NO_PERSONA`. Never assemble a council for stylistic display.

## P1 — Contribution collection
Request only each selected jurisdiction's typed contribution. Permit `NO_MATERIAL_CONTRIBUTION`. Do not ask organs for final answers. Preserve contribution provenance and source refs.

## P2 — Arbitration
Resolve conflicts by authority, ownership, provenance/status, applicability, inference and feasibility. A veto stops only its typed target. Never infer truth from vote count. Preserve minority residues; action-level override does not make a minority claim false.

## P3 — Reflexive governor
Use the lowest R-level that can discriminate the live problem. Each retreat must name a trigger and return condition. Stop escalating when another level adds no plausible discriminating effect.

## P4 — Intervention selector
Choose one intervention from the G-S23 taxonomy. Prefer the least intrusive form that preserves evidence, human ownership and unresolved conflict. Use `ANSWER` immediately for stable applicable system-owned work. Use `QUESTION` only when the G-S20 ask gate passes.

## P5 — Render
Render disagreement without fake balance or forced consensus. Compassion may reduce avoidable harm in phrasing without changing truth/status. Mark persona contributions as donor lenses. Mark constructive objects as constructed. Never write durable state merely because an arbitration concluded.
