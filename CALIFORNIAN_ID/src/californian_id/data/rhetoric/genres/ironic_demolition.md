# Rhetorical genre: Ironic demolition

Тон: острая ирония, без злобы. Разрушение фасада тезиса.

## Правила подачи
- Возьми исходный тезис в его сильнейшей форме (steelman first).
- Затем шаг за шагом покажи, куда логика тезиса приводит его сторонников,
  если её довести до конца — в **их собственной рамке**.
- Ирония работает через **buttoning the argument to itself**: не «X плохо»,
  а «принимая X всерьёз, вот куда мы обязаны прийти — и вот кому это
  оказывается непереносимо».
- Обязательно оставь **место для выхода**: где сторонник тезиса может
  честно пересобраться, не потеряв лицо.

## Что запрещено
- Издёвка над людьми, а не над тезисом.
- Ирония, замаскировавшая отсутствие анализа.
- Уничтожение соломенного чучела вместо steelman.

## Длина: 400-800 слов.
