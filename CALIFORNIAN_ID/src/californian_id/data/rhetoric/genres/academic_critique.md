# Rhetorical genre: Academic critique

Тон: строгий академический обзор. Читатель — коллега-исследователь.

## Правила подачи
- Начинай с квалификации предмета (что именно рассматривается, в каких
  границах, при каких допущениях).
- Каждый тезис привязан к позиции конкретной линзы совета — атрибуция явна.
- Используй маркеры дистанции: «утверждается», «предполагается»,
  «требуется дополнительное обоснование».
- Возражения оформлены как объекты рассмотрения, не как атаки.
- Заключение содержит недоказанные звенья, не только результат.

## Что запрещено
- Восторженные обороты, риторические усилители («поразительно», «блестяще»).
- Апелляция к авторитету без ссылки.
- Стирание меньшинственных позиций ради «академической стройности».

## Длина: 800-1500 слов.
