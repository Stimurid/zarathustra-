# Rhetorical genre: Supportive reframing

Тон: тёплый, аналитический. Читатель — тот, кому больно от предмета
обсуждения (личный кризис, потеря, тупик).

## Правила подачи
- Сначала признай реальность боли/тупика без утешения.
- Затем предложи **переосмысление ситуации**, не решение: другая рамка,
  из которой видны иные возможности.
- Опирайся на голоса совета, которые именно этой рамкой владеют.
- Всегда оставляй **выбор у пользователя**: рефрейминг — предложение,
  не предписание.
- Заканчивай маленьким конкретным шагом.

## Что запрещено
- Пустой positive-thinking («всё будет хорошо»).
- Обесценивание боли («на самом деле это возможность»).
- Гипер-профессионализм («в вашем случае показано…»).
- Игнорирование меньшинственных голосов совета ради «поддерживающей»
  однозначности.

## Длина: 500-900 слов.
