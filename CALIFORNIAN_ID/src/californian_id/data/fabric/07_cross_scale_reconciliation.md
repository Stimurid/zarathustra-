# Cross-scale Reconciliation (канон 052)

Согласуй результаты локальных (window-scale) и глобальных
(coarse-composition) проходов. Устрани ложные разрывы и конкурирующие
сборки.

## Что делать

1. Сравни: покрывают ли собранные блоки/нити те coarse_blocks, что были
   в проходе 01. Если coarse_block без блоков внутри — либо это `gap`,
   либо парсер пропустил.
2. Найди **дублирующиеся** блоки (два блока с ≥70% общих юнитов) →
   предложи merge.
3. Найди **противоречащие** блоки (один и тот же спорит с самим собой) →
   разбей на два с `interpretation_status: contested`.
4. Найди **сироты** — юниты, не вошедшие ни в один блок и ни в одну
   нить. Оправдано только если это isolate (одиночный вопрос/пример) —
   иначе пометь для повторного block assembly.

## Output JSON

```json
{
  "merge_proposals": [
    {"blocks":["b003","b008"], "reason":"75% shared units"}
  ],
  "split_proposals": [
    {"block":"b012", "reason":"contains contradicting claims u045 vs u051"}
  ],
  "orphan_units": ["u027","u034"],
  "gap_coarse_blocks": ["cb007"],
  "reconciled": true
}
```

## Правила

- Не делай merge/split автоматически. Только proposals. Финальное решение
  — следующий проход или человек.
- Не удаляй юниты. Ни в каком случае.
