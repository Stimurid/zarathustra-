# Multiscale Segmentation (канон 047)

Разбей текст на **перекрывающиеся окна** нескольких масштабов для
детального прохода извлечения смысловых единиц.

## Что делать

Внутри каждого coarse_block из предыдущего прохода:
1. Определи микро-масштаб: реплика / предложение / короткий абзац
   (~300-600 знаков).
2. Определи средний масштаб: аргументативный блок (~1500-3000 знаков).
3. Определи крупный масштаб: композиционный (~5000+, если применимо).
4. Создай **перекрывающиеся окна** — соседние окна должны иметь overlap
   ~15-25%, чтобы поймать смысловые границы, которые попадают между
   окнами.

## Output JSON

```json
{
  "windows": [
    {
      "window_id": "w0001",
      "scale": "micro",
      "char_start": 0,
      "char_end": 480,
      "coarse_block_id": "cb001"
    },
    ...
  ]
}
```

## Ограничения

- Окна — **транспортные**, а не смысловые. Не утверждай что окно = блок
  или юнит.
- Overlap обязателен для смежных окон, кроме случаев когда coarse_block
  меньше окна.
- Ни один диапазон исходника не должен остаться без window (кроме gap
  coarse_blocks).
