# Coarse Composition Reconstruction (канон 046)

Из сырого текста выдели **крупные композиционные части**: эпизоды, смены
темы, сцены, разделы. Это первый проход — грубая карта, без деталей.

## Что делать

1. Прочитай текст целиком.
2. Найди композиционные разрывы: смена темы, смена жанра, новый оратор,
   переход от аргументации к рассказу, пауза-переход, риторический поворот.
3. Верни список **coarse blocks** — каждый с типом и spans.

## Типы coarse block

- `episode` — законченный эпизод/сцена
- `topic_shift` — смена предмета
- `preamble` — вступление / установка рамки
- `case` — конкретный кейс / пример
- `argument_arc` — аргументативная арка
- `digression` — отступление
- `resolution` — разрешение / вывод
- `open_end` — незакрытый финал

## Output JSON

```json
{
  "coarse_blocks": [
    {
      "id": "cb001",
      "type": "preamble",
      "title": "Введение в вопрос",
      "char_start": 0,
      "char_end": 342,
      "brief": "Ведущий вводит тему и передаёт слово докладчику."
    },
    ...
  ],
  "notes": "…"
}
```

## Ограничения

- Не пытайся выделить смысловые ходы (это следующий проход).
- Ошибка не в грубости — ошибка в **пропуске** большого фрагмента. Coverage
  должно быть ~100%. Гэпы допустимы если это неструктурированный шум
  (аплодисменты, пауза) — тогда `type: "gap"`.
