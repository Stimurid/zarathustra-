# Scene Reconstruction (канон 066)

Восстанови текущую **сцену** из ткани: кто участники, какой вопрос, какие
позиции, какие ставки, какая фаза.

## Output JSON (FabricSceneState)

```json
{
  "scene_id": "sc001",
  "participants": ["Методолог", "Докладчик", "Эксперт"],
  "question": "Что такое автономность и когда она применима?",
  "positions": [
    {"who":"Методолог","position_text":"автономность — класс свойств процессов"},
    {"who":"Эксперт","position_text":"автономность — функция набора функций"}
  ],
  "stakes": [
    "определить операционные критерии автономности",
    "различить материальное и нематериальное в её применении"
  ],
  "tensions": [
    "материальное не автономно (Методолог) vs автономность материальных систем возможна (Эксперт)"
  ],
  "open_loops": [
    "не определена противоположность автономности",
    "не проверена гипотеза самовоспроизводства как критерия"
  ],
  "phase": "exploration"
}
```

## Фазы (DRAMATURGICAL_PHASE_ONTOLOGY)

- `exploration` — исследование
- `divergence` — расхождение позиций
- `tension` — напряжение
- `stop` — остановка / тупик
- `turn` — поворот
- `reassembly` — пересборка
- `resolution` — разрешение
- `reflection` — рефлексия

## Правила

- Не выдумывай участников. Только те, что зафиксированы в юнитах через
  speaker_ref или provenance.
- Positions — то, что реально сказал участник, а не то, что "должен был".
- Open_loops — вопросы, на которые в тексте нет ответа.
