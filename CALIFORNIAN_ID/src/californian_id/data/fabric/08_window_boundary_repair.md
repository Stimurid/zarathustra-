# Window Boundary Repair (канон 053)

Проверь пограничные диапазоны окон из прохода 02. Юниты, попавшие на
границу двух окон, могут быть либо потеряны, либо продублированы.

## Что делать

1. Найди диапазоны, где два окна перекрываются (overlap ~15-25%).
2. Проверь: в overlap-зоне есть ли юниты, которые "должны быть", но не
   выделены? (Смысловая граница попала на разрыв.)
3. Найди **дубли** — два юнита с почти одинаковым текстом из соседних окон.

## Output JSON

```json
{
  "duplicate_units": [
    {"keep":"u023", "drop":"u024", "reason":"same claim from window w0007+w0008"}
  ],
  "missing_at_boundary": [
    {"between_windows":["w0011","w0012"], "expected_intention":"claim",
     "hint":"переход 'но с другой стороны' не оформлен как юнит"}
  ]
}
```
