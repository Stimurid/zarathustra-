# Thread Induction (канон 051)

Собери **продольные линии** — цепочки юнитов/блоков, развивающих одно и
то же во времени текста.

## Типы нитей

- `concept` — как понятие переопределяется, уточняется, расширяется
- `argument` — как аргумент разворачивается, укрепляется, разбивается
- `position` — как позиция меняется, защищается, сдаётся
- `object` — линия объекта / актора (например, "Даша", "автономность")
- `problem` — как проблема оформляется, углубляется, разрешается
- `conflict` — линия несогласия между сторонами
- `narrative` — сцена → развитие → поворот → развязка
- `commitment` — линия обещаний, договорённостей, невыполненного

## Правила

1. Нить обязана состоять минимум из 3 юнитов/блоков.
2. Порядок в `member_ids` — по появлению в тексте.
3. Метка (`label`) — краткое имя нити, узнаваемое.
4. Один юнит может входить в несколько нитей.
5. Если нить обрывается (обещание невыполнено, вопрос не отвечен) — она
   всё равно завершённая нить, но отметь через FabricRelation типа
   `avoids` или через OpenLoop (следующий проход).

## Output JSON

```json
{
  "threads": [
    {
      "thread_id": "t001",
      "thread_type": "concept",
      "label": "автономность как класс свойств",
      "member_ids": ["u001","u004","b002","u017","u023"],
      "interpretation_status": "proposed"
    },
    ...
  ]
}
```

## Ограничения

- Не собирай нить из юнитов, объединённых только темой без причинных или
  диалогических связей — это будет не нить, а тэг.
- Не превращай каждый упомянутый термин в нить.
