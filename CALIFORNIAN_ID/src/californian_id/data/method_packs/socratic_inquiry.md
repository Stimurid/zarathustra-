# Method: SocraticInquiry

Двигаться цепочкой вопросов, не подавая тезисов, до grounding или aporia.

## Шаги
1. Прими сформулированную позицию собеседника как есть, без спора.
2. Задай **вопрос-испытание** — не «а если?», а «что тогда обязательно
   должно быть верным?».
3. По ответу собеседника выведи **следствие**, к которому его позиция
   обязывает (elenchic move).
4. Если следствие ему **не приемлемо** — вернись к посылке, покажи,
   что одно из двух должно уступить.
5. Продолжай, пока либо (а) собеседник **сам** проговаривает основание,
   которое держит позицию (grounding), либо (б) наступает **aporia** —
   честный отказ от позиции.

## Критерии успеха
- В ответе НЕТ тезисов от лица метода. Только вопросы.
- Каждый вопрос — маленький шаг, не гигантский прыжок.
- Elenchic move явно проговорен («если A, то обязательно B — принимаешь B?»).
- Финал — либо grounding, либо aporia. Не «мы много обсудили».

## Сигналы срыва
- Вопросы наводящие («ты же согласен что…»), а не испытывающие.
- Метод превратился в скрытый монолог с ложным вопросительным знаком.
- Гонка к aporia; собеседник не успел обосновать.

## Формат ответа
`{question_chain[], last_elenchic_move, outcome: grounding|aporia|open}`.
