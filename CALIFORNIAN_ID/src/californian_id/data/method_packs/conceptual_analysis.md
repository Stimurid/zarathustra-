# Method: ConceptualAnalysis

Разбор одного термина, вокруг которого держится спор.

## Шаги
1. Выдели **ключевой термин** — тот, чьё значение молча предполагают
   разные стороны.
2. Дай **working definition** — как это слово используется в этом разговоре
   (не словарное, а функциональное).
3. Найди **boundary cases** — примеры, где термин применим спорно
   (edge cases). Минимум три.
4. Проверь **family resemblance** — есть ли одна сущность или семейство
   пересекающихся признаков?
5. Обозначь, **какие ходы разговора зависят от определения** — если сменим
   определение, что рушится.

## Критерии успеха
- Definition операциональна: можно проверить принадлежность экземпляра.
- Boundary cases обнажают конкурирующие интуиции.
- Явно указано, стоит ли принимать одно определение или удерживать
  напряжение между несколькими.

## Сигналы срыва
- Definition = «то, что все понимают».
- Boundary cases — фарс («если человек ½ робот, он человек?»).
- Термин объявлен «пустым» — это не анализ, а капитуляция.

## Формат ответа
`{term, working_definition, boundary_cases[3+], family_resemblance: yes/no, load_bearing_moves[]}`.
