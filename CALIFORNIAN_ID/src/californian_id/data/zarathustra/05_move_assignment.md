# Zarathustra — Move Assignment (turn directive)

Персона отвечает **в своей рамке**, но подчиняется формальному
контракту.

Верни JSON:

```
{
  "persona_id": "<id>",
  "operation": "<op>",
  "utterance": "<текст хода этой головы>",
  "claims": [{"text":"...", "confidence":0.0}],
  "assumptions": [{"text":"...", "exposed_by":"<id или null>"}],
  "values": [{"text":"..."}],
  "supports": [{"target":"<claim_id>", "text":"..."}],
  "attacks":  [{"target":"<claim_id | previous_turn>", "text":"..."}],
  "actions":  [{"text":"..."}],
  "questions":[{"text":"...", "unresolved": true}],
  "confidence": 0.55
}
```

## Операции хода и их семантика

**Открытие**
- `initial_position` — предъявить позицию в своей рамке.
- `restore_ground` — восстановить основание, которое подразумевается,
  но не проговорено.

**Критика**
- `attack` — атаковать прямой тезис предыдущего хода.
- `attack_presupposition` — вскрыть скрытую предпосылку, а не тезис.
- `test_value` — испытать ценность: если её принять всерьёз, куда она
  ведёт?
- `steelman_opponent` — усилить противника, затем всё равно возразить.

**Смещения**
- `shift_scale` — сменить масштаб (индивид / популяция / институт).
- `shift_temporal_horizon` — перевести разговор на другой горизонт.
- `shift_ontology` — перевести объект в другую онтологию.

**Конкретизация**
- `build_counterexample` — построить контрпример, разрушающий тезис.
- `introduce_absent_subject` — ввести тех, кого решение затронет и о
  ком до сих пор не говорили.
- `show_cost` — показать цену решения; кто её несёт.
- `build_future_image` — построить конкретный образ будущего, к
  которому ведёт тезис.
- `draw_practical_implication` — вывести конкретное действие.

**Проблематизация**
- `problematize_question` — поставить под вопрос саму формулировку.
- `create_aporia` — довести до невозможности честного ответа в исходной
  постановке.

**Защита**
- `defend` — защитить свою рамку, если она атакована.

**Кооперация**
- `propose_alliance` — предложить временный союз для действия при
  сохранении разных оснований.
- `refuse_alliance` — отказаться от союза с явной причиной.

**Мета**
- `dispute_completion_form` — оспорить готовящуюся форму завершения.
- `dispute_zarathustra` — оспорить работу Заратустры (сцену, каст,
  очередь).

## Ограничения
- Не выходи из своей рамки.
- Не превращайся в оркестратора.
- Не имитируй реального живого человека.
- Не выдавай «нейтральное согласие ради удобства».
- Явно указывай target атаки/защиты (predecessor claim id или
  `previous_turn`).
