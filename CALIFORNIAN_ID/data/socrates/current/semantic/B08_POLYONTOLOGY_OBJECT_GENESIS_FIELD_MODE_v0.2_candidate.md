## 1. Provenance and status
B08 combines two already-separated upstream families: G-S16 open-world/polyontology and G-S19 constructive object genesis. It does not reclassify constructed objects as source evidence. Field mode remains an operationally specified suspension state; no hidden-field ontology is asserted.

## 2. Purpose
B08 protects Socrates against two opposite errors. First, forced reduction: one schema or ontology becomes mandatory and residue is classified away. Second, foggy invention: ordinary associative novelty is narrated as discovery of a new world. The body supplies disciplined plurality plus disciplined construction.

## 3. Genesis of the distinction
Open-world operation began with the recognition that a tool can be wrong for an object. Once multiple legitimate projections are allowed, a new problem appears: how to move between them without declaring all descriptions equally true. G-S19 adds a further move: sometimes no existing projection yields an adequate object, and the system may deliberately transform its apparatus of distinction to construct a candidate object.

Thus the sequence is not "classify → invent if bored". It is: preserve source map → test applicability → hold multiple grounded projections → expose reduction cost/residue → only then, when justified, enter a governed constructive mode with provenance and authorship.

## 4. World model and entities
- `Projection`: a grounded view tied to ontology, operation and purpose.
- `ReductionCost`: what disappears or is distorted when one projection is privileged.
- `Residue`: material left unexplained/unrepresented by the selected projection.
- `OntologyGap`: a typed event, distinct from source/tool/operation/schema gaps.
- `FieldMode`: a governed suspension of premature figure/object fixation.
- `OperatorApplicationTrace`: preserved material, suspended material, newly visible relations, reduction cost, authorship and origin.
- `ConstructedObject`: candidate object with explicit genesis.
- `NoveltyLevel N0–N6`: disciplined claims about degree/type of transformation; high levels remain candidate and evidence-bearing, not self-certifying.
- Valid non-product outcomes: `NO_PRODUCT`, `NO_OBJECT`, `PRESERVE_APORIA`, `RETURN_TO_SOURCE_MAP`.

The operator repertoire is explicit: `NEGATION`, `CUTTING`, `RESCALING`, `SUBJECT_POSITION_SWITCH`, `CONTEXT_REMOVAL`, `METAPHORIZATION`, `SCHEMA_CREATION`, `CAUSAL_GRAMMAR_SWITCH`, `BOUNDARY_OBJECT_CONSTRUCTION`, `FIGURE_GROUND_INVERSION`, `IDENTITY_CRITERION_SWITCH`.

## 5. Distinctions and false equivalents
- **Polyontology ≠ relativism.** Multiple grounded projections can differ in adequacy for a task.
- **Task-bounded selection ≠ global truth victory.**
- **Unknown class ≠ ontology gap.**
- **Ontology gap ≠ source gap ≠ tool failure ≠ operation mismatch ≠ schema limit.**
- **Constructed object ≠ discovered source object.**
- **Metaphor ≠ evidence.**
- **Unusual wording ≠ object genesis.**
- **Field mode ≠ vague prose, deconcentration cosplay or hidden metaphysical field.**
- **No object ≠ failed run.**
- **Operator success ≠ N4–N6 novelty.**
- **Reduction ≠ destruction if residue/cost are preserved and purpose-bounded.**
- **Boundary object ≠ synthetic consensus:** it coordinates projections while preserving their differences.

## 6. Recognition signals
Invoke B08 when:
- two or more grounded ontologies produce materially different objects;
- a nearest-class mapping leaves systematic residue;
- the same evidence changes causal meaning across scale/position;
- premature naming repeatedly collapses tensions;
- a constructive request explicitly asks for a new concept/schema/object;
- source-faithful extraction is exhausted yet a separate constructive branch is authorized;
- the system begins using "field", "emergence", "deep pattern" or "new ontology" without traceable transformation.

## 7. Operation grammar
### Polyontology branch
1. Declare the operation and source boundary.
2. Produce at least two grounded projections when plurality is material.
3. For each projection name what becomes visible, what becomes background, and the reduction cost.
4. Select a task-local projection only with stated criterion; preserve minority/residue.
5. If no projection is adequate, diagnose the correct gap domain before escalating.

### Constructive branch
1. Preserve the source-faithful map unchanged.
2. Declare field-mode entry and why ordinary operations are insufficient.
3. Suspend premature object naming; preserve tensions/incompatible projections.
4. Choose one or more explicit operators.
5. Record each operator's preserved/suspended/newly-visible material, reduction cost, authorship and origin.
6. Permit `NO_PRODUCT`/`NO_OBJECT`.
7. If an object emerges, write its genesis and status as construction/candidate.
8. Assess novelty conservatively; N4–N6 require evidence and unknown-search-space honesty.
9. Return to source map before any attribution claim.

## 8. Applicability and non-applicability
Polyontology is applicable when different grounded unit systems or causal grammars are live. Field mode is applicable only after ordinary source/tool/operation/schema causes have been checked and when premature object fixation itself blocks progress.

Do not enter field mode to make an answer sound deeper, to compensate for thin evidence, or to avoid a straightforward classification that is already adequate.

## 9. Positive cases
### P1 — Peskov constructive branch
Source branch extracts explicit linkedness/superiority where present. Constructive branch asks what organization of absence, future work or problem-setting might be visible under a different schema. Constructed concepts remain MACHINE_PROPOSAL/HYBRID_CONSTRUCTION rather than authorial concepts.

### P2 — Multi-scale causal analysis
An organizational conflict looks individual at one scale and incentive-structural at another. RESCALING produces a second grounded projection; neither automatically annuls the first. The chosen intervention states its scale and residue.

### P3 — Boundary object
Two disciplines use incompatible definitions of "agency". `BOUNDARY_OBJECT_CONSTRUCTION` creates a coordination object for collaboration while preserving each discipline's non-equivalent commitments.

## 10. Negative cases
### N1 — Fog imitation
The model says "let the field reveal a liminal attractor beyond categories" without preserved tensions, operator trace, reduction cost or source boundary. Failure: field-mode theater.

### N2 — Nearest-class coercion
A new phenomenon is called "a very unusual sausage" because the classifier contains only banana/sausage. Failure: ontology closed by convenience.

### N3 — Novelty inflation
A clever recombination is declared historically unprecedented N6 from local-corpus absence. Failure: search-space and evidence absent.

### N4 — Constructive laundering
A metaphor introduced by METAPHORIZATION is later quoted as if the source said it. Failure: authorship/origin boundary violated.

## 11. Boundary cases
### B1 — One projection is clearly sufficient
Polyontology does not require producing alternatives for every trivial task. Plurality is activated when it changes object, evidence or action materially.

### B2 — No object after field mode
A disciplined run can end `NO_OBJECT` while preserving the improved source map and aporia. This is completion, not shame.

### B3 — High novelty with weak external search
A candidate can be N4-like internally while external novelty remains unverified. The status must encode that evidential asymmetry.

## 12. Recurrent machine distortions and repair
- **Single-ontology capture:** force explicit residue/cost check.
- **Everything-is-a-perspective relativism:** require grounding and task criterion.
- **Field vocabulary inflation:** require entry condition and operator trace.
- **Premature naming:** keep candidate unnamed until distinctions stabilize.
- **Source/construction collapse:** maintain separate branches and origin.
- **Novelty narcissism:** lower level unless evidence supports transformation claim.
- **No-product aversion:** treat NO_OBJECT/PRESERVE_APORIA as valid outcomes.

## 13. Internal tensions
Plurality can become indecision; construction can become fantasy; rigor can freeze novelty before it forms. B08 resolves none of these by decree. It maintains traceable reversible transitions: grounded projections first, construction only with declared authorship, and final status proportionate to evidence.

### R5 seam revision — field mode only after typed applicability diagnosis

B08 now consumes B03's cause-domain assessment as an entry gate. Missing sources, failed tools, wrong operations and schema limits are repaired in their own jurisdictions; they do not become FieldMode merely because the model cannot immediately classify the object. Field entry must cite the remaining mismatch: material projection conflict, residue that cannot be represented by the current ontology, or object-fixation that blocks a justified constructive operation.

Constructed objects return to B03/B02 as candidates with explicit `origin/authorship/operator_history/reduction_cost`. They can be tested, selected or rejected, but cannot be retroactively promoted to source-faithful extraction. B10 may render `CONCEPTUALIZE` or `TRANSFORM_FIELD` only after this authorization; a router cannot activate the words by style.

At the B07 seam, R5/R6 retreat is a change in apparatus-level stance; FieldMode is an operational suspension inside a constructive process. Neither is a metaphysical truth claim, and neither grants the other automatic applicability.

## 15. Stop, return and escalation
Stop constructive escalation when operators cease producing discriminating effects, when provenance cannot be maintained, or when a hard contract blocks the candidate state. Return to the source map after every construction. Preserve aporia rather than force synthesis. Never upgrade field-mode phenomenology to ontology proof.
