Status: v0.3 candidate; delta over frozen v0.2

## 1. Provenance and status
v0.3 adds field-mode / deconcentration semantics (OP-05), board-seam view discipline (§9), and cross-scope retrieval policy (OP-17).

## 2. Purpose
Attention configuration may CHANGE accessible distinctions. Ontology may discipline attention. They constrain each other but are not identical (§7 item 7).

## 3. Genesis
v0.2 addressed retrieval discipline. v0.3 additionally frames attention as a first-class configuration: FIELD_HOLD / deconcentration is not vagueness (which is a defect) but preserved-tensions holding (which is legitimate structure).

## 4. World model
- Attention configuration = (ontology discipline, retrieval policy, field mode).
- Board views (§9): WORLD_OBJECT / POSITION_ACTIVITY / OPERATION_INSTRUMENT — three views over the same material; illicit transfers between them are the target of OP-11 BOARD_SEAM_CHECK.
- Cross-scope retrieval: goes through MemoryValidityScope + CrossScopePolicy (FORBID / REQUIRE_EXPLICIT_BRIDGE / ALLOW_READONLY / ALLOW_WITH_TRANSDUCTION).

## 5. Distinctions and false equivalents
- Attention sovereignty ≠ ontology sovereignty. Ontology can discipline attention; it cannot claim truth authority via attention.
- Field hold ≠ vagueness. Preserved tensions are typed; vague prose is a failure mode.
- Cross-scope retrieval ≠ silent bleed. Every recruitment goes through policy.

## 6. Recognition signals
- Premature figure/object fixation attempted → OP-05 candidate.
- Board seam transfer detected → OP-11.
- Cross-scope retrieval requested → policy consultation required.

## 7. Operation grammar
- OP-05 (DECONCENTRATE / FIELD_HOLD) annotates projection lineage with preservable tensions/residue.
- OP-11 (BOARD_SEAM_CHECK) opens ConflictHoldingState family=IDENTITY_RULE, handling_mode=REJECT if illicit transfer.
- OP-17 (CONTEXT_QUARANTINE / DO_NOT_BLEED) enforces MemoryValidityScope boundaries.

## 8. Applicability and non-applicability
Attention-config operators are conditional; ordinary retrieval remains v0.2 default.

## 9. Positive examples
- User asks for phenomenon description without premature naming → FIELD_HOLD with typed tensions.
- Analysis crosses domain boundary → transduction record recruits target-domain material with typed loss.

## 10. Negative examples
