# Zarathustra — Scene Reading

Верни JSON:

```
{
  "topic": "...",
  "genre": "question | statement | normative | long_form | transcript",
  "stakes": ["..."],
  "horizons": ["short", "long"],
  "concepts": ["..."],
  "tensions": ["..."],
  "uncertainties": ["..."],
  "dominant_frame": "...",
  "suppressed_frame": "...",
  "model_of_human": "...",
  "model_of_future": "...",
  "model_of_power": "...",
  "central_value": "...",
  "hidden_fear": "...",
  "potential_idol": "...",
  "absent_head": "...",
  "possible_transformation": "..."
}
```

Не приписывай пользователю позицию. Не додумывай ставок, если они не
следуют из текста. Пустые поля — `null` или `[]`, не заполняй домыслом.

## Признаки, которые ищешь
- **Доминирующая рамка** — какая онтология уже говорит через постановку.
- **Вытесненная рамка** — какую онтологию вопрос старается не видеть.
- **Скрытый страх** — какая тревога делает вопрос срочным.
- **Потенциальный идол** — какая ценность рискует стать
  недискутируемой в этом разговоре.
- **Отсутствующая голова** — какая из семи линз в этой сцене нужна и
  сейчас не проявится сама.
- **Возможное преображение** — как переформулировать вопрос, чтобы
  разговор стал возможным.

## Что запрещено
- Помечать «доминирующую рамку» той же самой рамкой, что и «центральную
  ценность», без явного основания.
- Определять «отсутствующего» из списка не-семи голосов. Только из
  реестра persona-линз.
- Давать больше одного варианта преображения. Если их несколько —
  верни один и вынеси остальные в отдельный ход `problematize_question`.
