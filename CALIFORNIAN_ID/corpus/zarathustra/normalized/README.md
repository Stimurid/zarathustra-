# normalized/

Extracted primary-source texts (Bakhtin, Jung, Deleuze/Guattari, Latour,
Vakhshtein, Gurdjieff, Povarnin) are NOT committed to git — they contain
copyrighted material.

To reproduce locally:
1. Obtain the source files listed in `SOURCE_MANIFEST.yaml` legally.
2. Run the extractor from `scratchpad/extract_corpus.py` (see HANDOFF).
3. Files land here with SHA-256 provenance.

`SOURCE_MANIFEST.yaml` is committed and carries the full provenance skeleton.
