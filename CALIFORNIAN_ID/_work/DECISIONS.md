# Decisions log

Хронология содержательных решений этой сборки. Каждая запись
воспроизводима из canon-контрактов.

## DEC-001 — Runtime = Python 3.11+, mock-first
- **Почему:** в трёх дополнительных файлах не оказалось рабочего
  skeleton; работающий референс `digital_personality_runtime` — YAML +
  Markdown без cross-platform runtime; на Windows-хосте пользователя
  Python 3.13/3.14 доступны.
- **Что даёт:** end-to-end работоспособность без внешних API и без
  установки dep'ов сверх pyyaml/pytest.
- **Обратимость:** полностью обратимо; ядро отсоединено от provider.

## DEC-002 — Персоны как линзы, не имитации
- **Почему:** canon-контракт
  `CULTURAL_PERSONA_LENS_CONTRACT.md` явно запрещает impersonation.
  Задача заказчика говорит о «трансгуманисте», «лонгтермите» и т.д. —
  это идеологические позиции, не живые люди.
- **Что даёт:** реальные семь персон, которые придут позже, наследуют
  тот же контракт; test `test_no_persona_impersonates_a_real_person`
  становится canonical acceptance criterion.
- **Обратимость:** нет и не надо.

## DEC-003 — Заратустра ≠ голос
- **Почему:** и `Orc_agent_met.docx`, и Group Soul Assembly Method
  явно требуют, чтобы оркестратор не имел собственной идеологической
  позиции.
- **Что даёт:** `synthesize` возвращает `epistemic_status: candidate` и
  никогда не приписывает совету волю там, где её нет.
- **Обратимость:** обратимо, но было бы нарушением канона.

## DEC-004 — Sequential-only inner dialogue
- **Почему:** описание задачи заказчика прямо говорит «субличности не
  общаются параллельно; оркестратор заставляет их спорить
  последовательно». Плюс канонический архетип
  `world_value_position_narrative_to_group_soul` также последовательный.
- **Что даёт:** детерминированный тест-порядок, воспроизводимые trace.
- **Обратимость:** обратимо через добавление `AgentSquad`-ветки
  (см. `promt donors/промпты бобера.docx` — там 6 shapes агентных
  оркестраций).

## DEC-005 — Lexical (BM25) RAG fallback
- **Почему:** vector store неоправдан для семи fixture-персон без
  реальных корпусов; интерфейс `LexicalPersonaRetriever` заменяем.
- **Обратимость:** полностью обратимо (один интерфейс `retrieve`).

## DEC-006 — Feynman и Telegram — только контракты
- **Почему:** реального API Feynman в локальных файлах нет; Telegram bot
  skeleton нет; писать mock, выглядящий как реальный, — вредный
  антипаттерн (см. пункт 3 запретов CLAUDE_CODE_HANDOFF).
- **Что даёт:** пакет не претендует на подключения, которые не проверял.

## DEC-007 — Схемы = dataclasses, не jsonschema
- **Почему:** минимизировать dep'ы для MVP; canonical schemas в canon
  можно подключить позже без миграции кода.
- **Обратимость:** тривиально.

## DEC-008 — CLI как реальный «первый» host
- **Почему:** обязательное требование handoff-спеки: CLI должен
  запускаться и быть настоящим доказательством работоспособности.
- **Что даёт:** любой человек может воспроизвести demo одной командой.

## DEC-009 — Fast=5 turns / Deep=12 turns
- **Почему:** соответствует спеке; fast достаточно, чтобы 3–4 голоса
  проявили конфликт; deep даёт пространство для мультираундового
  attack-defend-synthesis_challenge.
- **Обратимость:** редактируется в `config/runtime.yaml`.
