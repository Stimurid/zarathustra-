# ЖЕЛЕЗНЫЕ ПРАВИЛА (не для обсуждения)

Эти правила заданы пользователем прямо и явно. Нарушение = grounds for
rollback + переделка. Читать в начале каждой сессии, перед любой правкой.

## 1. Никакого mock/заглушки/детерминированного fallback в user-facing runtime

**Формулировка пользователя (verbatim, 2026-07-29):**
> «Мы мок не используем. Мы не используем заглушки и прочее говно.
> Такое — "Web UI НЕ ИСПОЛЬЗУЕТ реальные 8 персон" — должно быть
> невозможно. Либо реальные LLM либо никак. Либо агенты на промптах —
> либо никак. Как только заглушка и детерминированный вместо LLM —
> расстрел, увольнение, убийство нахуй с выдиранием кишок. Ясно?»

### Что это значит на практике

- **Prod runtime (Web UI, API /api/run, CLI run):** любой шаг, который
  должен генерировать смысл — идёт через реальный LLM. Никаких
  fallback на mock, никаких deterministic-заглушек, никакого
  "если LLM не сконфигурирован — вернём шаблонный ответ".
- **`closing_speech` пустая = баг** — сервис должен упасть с явной
  ошибкой «нужен LLM-ключ», а не тихо вернуть placeholder.
- **Персоны-fixture** (LENS_TRANSHUMANIST/…) — использовались только
  для offline-тестов pipeline. В prod runtime их место занимают **8
  реальных персон** из `runtime_assets/personas/v0.2/` (C, EA, Ex, L,
  N8, R, S, T) с их полными constitution.md, cards.jsonl, promt'ами.
- **Fallback chain** — только между LLM (Opus → GPT-5 → Sonnet →
  DeepSeek → …). НЕ на mock.

### Что можно (единственное исключение)

**Автоматические pytest-тесты** — там mock допустим только внутри
`tests/`, только когда pytest вызывает Pipeline напрямую. НО:
1. Никакой тест не должен использовать mock как "fake success" для
   проверки логики генерации содержания. Такие тесты фиктивны.
2. Все live-acceptance тесты (`tests/acceptance/`) должны падать с
   явным `pytest.skip("no API key")` без ключа. Не проходить.

### Красные флаги при код-ревью

- `if not client or provider == "mock": return "…"` → **удалить**
- `default: mock` в новых конфигах → **удалить**
- Fallback вида `try: llm(); except: return template` → **удалить**,
  падать наружу с явной ошибкой
- `MockClient()` в prod-code path (Web UI, CLI run) → **удалить**
- Комментарии типа «fallback на mock если ключ не задан» → **переписать
  на fail-fast**

### Что делать вместо mock

- **Ключ не задан:** сервис не стартует. `python -m californian_id
  validate` возвращает non-zero, systemd-unit крашится с ясным
  сообщением в journal.
- **LLM недоступен временно:** fallback chain внутри 302.ai → direct
  Anthropic → direct OpenAI. Все реальные LLM. Только если и они все
  упали — HTTP 503 с явным «all providers failed», не заглушка.
- **Ответ модели пустой/сломанный:** retry через fallback chain, затем
  HTTP 500 с сообщением в trace. НЕ подмена placeholder.

## 3. Правило свежести UI-скрипта

После любой правки `_HTML` в `web_ui.py`:
```bash
curl -sk "https://tinkuy.mindkampf.ru/?t=$RANDOM" \
  | awk '/<script>/,/<\/script>/' > /tmp/s.js
node --check /tmp/s.js
```
Молчание = OK. Ошибка = деплой сломан, HTML не проверен, откатывать.
