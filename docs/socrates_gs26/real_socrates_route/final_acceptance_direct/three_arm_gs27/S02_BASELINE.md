# Сравнение двух моделей локализации

Поскольку конкретные модели не указаны, привожу сравнение двух базовых подходов к локализации ПО и контента.

## 1. Строковая (ключ-значение)

**Суть:** тексты вынесены в файлы ресурсов (`.json`, `.po`, `.xliff`, `.resx`), код обращается к ним по ключу: `t("welcome.title")`.

**Плюсы:**
- Простая интеграция с CI/CD и TMS (Crowdin, Lokalise, Weblate).
- Дёшево масштабируется на десятки языков.
- Переводчик работает без доступа к коду.
- Поддержка плюрализации (ICU MessageFormat), интерполяции, контекста.

**Минусы:**
- Разрыв контекста: переводчик не видит, где строка появляется.
- Проблемы с порядком слов и согласованием в языках со сложной морфологией (русский, арабский, финский).
- Дублирование строк, «мёртвые» ключи.

## 2. Сегментно-контентная (перевод документов/страниц целиком)

**Суть:** локализуется исходный документ или разметка (Markdown, HTML, MDX), часто через параллельные версии файлов или headless CMS с поддержкой мультиязычности (Strapi, Sanity, Contentful).

**Плюсы:**
- Переводчик видит полный контекст и структуру.
- Естественно для маркетинговых сайтов, документации, лендингов.
- Возможна культурная адаптация, а не пословный перевод (транскреация).
- Легко подключается MT + post-editing на уровне абзаца.

**Минусы:**
- Синхронизация версий между языками — постоянная боль.
- Изменение одного слова в исходнике требует ревью всех локалей.
- Плохо ложится на интерфейсные микротексты (кнопки, ошибки).

## Когда что выбирать

| Кейс | Модель |
|---|---|
| SaaS-интерфейс, мобильное приложение | Строковая |
| Документация, блог, лендинги | Сегментно-контентная |
| Гибрид (продукт + маркетинг) | Обе, разделённые по слоям |
| LLM-пайплайн, промпты | Сегментно-контентная с версионированием |

## Ключевой практический совет

Не смешивайте слои в одном хранилище. UI-строки — в TMS с ключами; длинный контент — в CMS или Git с параллельными файлами. Иначе получите ад ревью и рассинхрон версий.

Если имелись в виду конкретные модели (например, i18next vs FormatJS, gettext vs XLIFF, или две LLM для машинного перевода) — уточните, сравню предметно.
